# Как выложить страницу (10 минут)

1. Зарегистрируйтесь на github.com, если аккаунта нет. Username станет адресом сайта, поэтому выбирайте аккуратный вариант: например, `dbessedin` даст адрес `dbessedin.github.io`.
2. Создайте новый репозиторий. Имя репозитория должно быть строго `<ваш-username>.github.io` (например, `dbessedin.github.io`). Видимость: Public.
3. Загрузите в репозиторий три файла: `index.html`, `cv.pdf` и `photo.jpg` (см. ниже) (кнопка Add file, затем Upload files, затем Commit).
4. Всё. Через одну-две минуты страница откроется по адресу `https://<ваш-username>.github.io`.

## Обязательный шаг с фото

Переименуйте вашу фотографию (unnamed.jpg из папки Downloads) в `photo.jpg` и загрузите её в репозиторий рядом с `index.html`. Страница ищет именно файл `photo.jpg`; пока его нет, вместо фото показывается кружок с инициалами DB.

## CV

`cv.pdf` уже в комплекте (это одностраничное CV). Оно показывается прямо на странице во встроенном просмотрщике, плюс две кнопки: открыть на весь экран и скачать. Когда CV обновится, загрузите новый файл с тем же именем `cv.pdf`, больше ничего менять не нужно.

## Что править в тексте

Текст страницы на английском, редактируется прямо на GitHub (карандаш на файле `index.html`). Секции: About, Research, In progress, Beyond research, Contact. Правки применяются через Commit и появляются на сайте через минуту.
